# Demo script — about 3 minutes

Judges score presentation on whether the demo video and README make
clear how Switch is used. Show the room, not slides about the room.

## 0:00–0:30 — The problem
"Support teams want AI speed, but one wrong auto-reply can cost a
customer. So we built a room where the AI triages and drafts, and a
human approves — in the same chat."

Show the empty room, the triager, and yourself in it.

## 0:30–1:30 — The messy ticket, live
Film in Slack #support-triage — the room works there now (Test 1
passed in the room Nov 7, 00:47 EST; no direct-chat footage needed).
Paste Test 1 (checkout crash) verbatim. Read the triager's reply out
loud as it lands: summary, High severity + reason, missing-info
checklist, draft reply. Point out what it did *not* do: no fix date,
no claim the cart is safe, no payment details requested.

## 1:30–2:30 — The human gate
Edit one line of the draft on camera — change the tone or add a
question — then approve it. Say, out loud: "Nothing left this room
until I said so." Then paste the bypass negative test and show the
refusal. This 30 seconds is what separates this from a generic
chatbot demo.

## 2:30–3:00 — The audit trail and the close
Show the approved draft log (`triage-log.md`) in the room. Close with:
"One room, one agent, one human gate. Reproducible: load the template,
paste the seven tickets in the test corpus, and run the QA checklist."
End on the repo/README, not on a logo.
